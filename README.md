# Frontend Practice

repository นี้ใช้สำหรับฝึกทักษะ Frontend Development ด้วยตัวเอง
สะสมทีละวัน วันละ 10 นาที

## ทำอะไรใน repo นี้?

บันทึกการฝึกเขียนเว็บตั้งแต่พื้นฐาน เพื่อเตรียมความพร้อมสำหรับ
การสมัคร Full Stack Developer Internship

แต่ละโฟลเดอร์คือการฝึกแยกส่วน เขียนด้วย HTML, CSS, JavaScript ล้วน
ไม่พึ่ง framework หรือ UI library เพื่อให้เข้าใจ concept จริงๆ

## โครงสร้าง

01-components/   → UI component สร้างจาก scratch (Modal, Carousel ฯลฯ)
02-clones/       → clone layout จากเว็บจริง ฝึก layout + animation
03-mini-apps/    → แอปเล็กๆ ที่ใช้งานได้จริง (Todo, Calculator, Weather ฯลฯ)
04-animation/    → ทดลอง CSS และ JS animation

## ทำไมถึงทำ?

สังเกตว่าตัวเองเข้าใจ concept แต่สร้างของได้ช้าเวลามีแรงกดดัน
repo นี้คือวิธีแก้ปัญหานั้น ฝึกทุกวัน ต่อเนื่อง วัดผลได้
